# NoNetApp - Local Network Monitor for Windows

تطبيق واجهة رسومية بسيط مبني باستخدام بيئة عمل .NET 8 لـ Windows Forms ومكتوب بلغة C# لمراقبة وفحص الأجهزة المتصلة بالشبكة المحلية.

## الميزات
- فحص سريع وتلقائي للنطاق الفرعي (Subnet) للشبكة المحلية عبر حزم Ping متوازية وغير متزامنة.
- عرض تفصيلي لعناوين الأجهزة (IP Address, MAC Address).
- واجهة مستخدم داكنة (Dark Mode UI).
- جاهز للبناء والتشغيل مباشرة على أنظمة ويندوز.

## المتطلبات
- بيئة تشغيل .NET 8.0 SDK أو أحدث.
- نظام تشغيل Windows.
